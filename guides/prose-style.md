# Prose style

How every brief, report and summary in this repo should read: like a sharp
analyst wrote it for a busy colleague. The principles adapt Matt Pocock's
writing skills (`vendor/mattpocock-skills/`); the tells list at the end is for
the editing pass only.

## Targets

1. **Point first.** The first sentence of each paragraph makes the claim.
   Support follows.
2. **Concrete.** Name the organisation, the amount, the date, the programme.
   Replace an intensifier with the number behind it: "a £45m contract", not
   "a major contract".
3. **Ground before use.** A reader meets a concept, defined, before any
   sentence leans on it. Order sections so each depends only on what came
   before (information is a directed acyclic graph).
4. **Every paragraph earns its place.** Test: *if I cut this, what breaks?*
   If nothing breaks, cut it.
5. **One job per sentence.** A sentence doing two jobs becomes two sentences.
6. **Short paragraphs.** In a brief, about 240 characters per paragraph at
   most. In a report, three or four sentences at most.
7. **Format follows shape.**
   - Prose carries argument.
   - A list carries truly parallel items.
   - A table carries anything where the same fields repeat three or more
     times.
   - Quote when the exact wording is the point; otherwise paraphrase.
8. **Plain words.** Use, help, show, start, change, important.
9. **Calibrated, once.** State confidence once, where it applies, using the
   wording rules in `skills/write-brief/SKILL.md`. Elsewhere, write
   declaratively.
10. **Natural rhythm.** Mix short and long sentences as the content needs.
    Paragraph lengths vary.
11. **Punctuation.** Use commas, colons, full stops and parentheses. Leave
    out em-dashes entirely: rewrite the sentence with whichever of those it
    actually needs.
12. **Headings are labels.** "Contract awards, 2024–25" and not a slogan.
13. **End when done.** The last paragraph adds something: an implication, an
    open question, a next step.
14. **UK English**, neutral register, no emoji, no exclamation marks.

## Tells (editing pass only)

Read a finished draft against this list. Every hit gets rewritten into the
targets above. Do not swap in a synonym; rewrite the sentence.

**Vocabulary**
- delve, tapestry, realm, landscape (as metaphor), ecosystem (as metaphor), journey
- pivotal, crucial, vital, robust, seamless, cutting-edge, game-changing, transformative, ever-evolving
- leverage, harness, unlock, empower, foster, navigate (as metaphor), underscore, showcase, bolster, streamline
- "a testament to", "plays a key role", "in today's … world", "it is important to note", "it is worth noting"
- furthermore, moreover, additionally, notably, ultimately, overall (as openers)

**Structures**
- "It's not X, it's Y" / "not just X, but Y"
- Groups of three by reflex (three adjectives, three parallel clauses)
- Rhetorical questions, and colon reveals ("The result? …")
- Signposting ("Let's explore", "In this report we will", "Here's the thing")
- A closing paragraph that restates what came before ("In conclusion", "In summary")
- Every bullet opening with a bold label and a colon (keep this device for
  the key-findings list only)
- Stacked hedges ("may potentially", "could possibly suggest")
- Vague attribution ("experts say", "studies show") without a source ID
- Balanced pros and cons offered for the sake of balance rather than evidence
- Paragraphs all the same length; sentences all the same shape
