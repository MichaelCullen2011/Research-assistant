# Write brief

Input: `brief.md`, `findings.md`, `sources.md`. Output: `outputs/brief.md`
built from `templates/output-brief.md`.

## Rules
- **Length**: one to two pages, about 400–800 words excluding the source
  table.
- **Answer first.** The *Bottom line* answers the main question directly in
  2–4 sentences, including how confident you are.
- **Key findings**: 3–7, ordered by importance to the reader's purpose. Each
  one has a bold headline sentence, one or two sentences of support, and source
  IDs. Use **only** findings from `findings.md`. If you need something that is
  not there, go back to capture-findings first.
- **Wording follows confidence.** High: state plainly. Medium: "evidence
  suggests". Low: "early or single-source reports indicate".
- **One visual** if it helps (see `guides/visuals.md`). A comparison table or
  timeline usually works best for a brief.
- **Implications** are analysis. Tie them to the brief's purpose and
  audience.
- **Sources table**: list only the sources cited in the brief, with clickable
  links.
- Write to `guides/prose-style.md`.

## Hand off

- Otherwise go to `skills/edit-prose/SKILL.md`, then `skills/verify/SKILL.md`.
